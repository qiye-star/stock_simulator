# css/features/ — 玩法样式（⑤ 起）

与 `js/features/<name>/` 一一对应，在 `index.html` 中排在 `pages.css` 之后加载。

| 文件 | 职责 |
| --- | --- |
| `news.css` | 快讯 tab（过滤胶囊、日分组、重大卡）、行情快讯条、收盘小结“今天的大事”、事件详情（传导节点、日 tab、锁提示）、产业链（行、中心、候选）、个股“相关事件” |
| `predict.css` | 预测卡弹层（横幅、5 档分段、把握滑块、排序芯片）、结算复盘、我的预测列表、积分卡、校准曲线、情报卡与抽屉、称号墙、情报按钮 |
| `replay.css` | 真实复盘：选关与关卡卡、会话（阶段条、股票卡、K 线与“未来”分隔、消息、预测题、交易与推进）、下单抽屉、揭示页（积分、真身、事件影响、题目结果、资产曲线） |
| `challenge.css` | 每日挑战：玩法页挑战卡与回合条、挑战页（状态卡、回合、各轮、往期）、排行榜（我的行、表头与行）、复盘（成绩格、公平性键值）、挑战存档横幅 |
| `pm.css` | 预测市场：市场卡、选项行与概率条、曲线、买卖面板、结算卡、玩法页分区（只用 accent 与中性色） |

## 规则
- 只用 `css/tokens.css` 的变量，不写色值（`rgba(0,0,0,…)` 阴影/遮罩除外）。
- 红绿只用于行情数据（传导节点的涨跌底色与数字 `.prop-node--up/--down`）；“事发”、“重大”、强调用 `--accent` 系列。
- 触控元素最小 `--tap`（44px）；动画在 `prefers-reduced-motion: reduce` 下关闭。
- 类名前缀与功能对应：`news-*`、`prop-*`、`event-*`、`chain-*`、`lock-note`、`later-*`、`cs-event`、`news-strip`；挑战用 `challenge-*`、`ch-*`、`round-bar*`、`board-*`。
