# 股市模拟器 · 手机端网页原型

深色、克制、数字优先的手机端网页，适配 375–430px 手机屏。纯静态（无构建），现已对接真实后端：所有请求走同源 `/api/v1`，行情用 WebSocket 实时推送（断线自动退化为轮询）。也保留假数据模式用于离线看样式。

## 快速开始

无需安装依赖，也不用构建。

```bash
# 1) 启动后端（端口 8000，详见 backend/README.md）
cd backend && uv run alembic upgrade head
uv run uvicorn --factory stocksim.main:create_app --host 0.0.0.0 --port 8000

# 2) 启动开发服务器：静态文件 + /api（含 WebSocket）反向代理
node mobile-prototype/dev-server.mjs
# 电脑：http://localhost:18765/   手机：http://<电脑IP>:18765/
# 可选环境变量：PORT=18765  HOST=0.0.0.0  BACKEND_URL=http://localhost:8000
```

首次打开进入登录页，可直接注册账号；没有存档时会自动创建「主存档」（100 万、每手 100 股、T+1）。会话是后端设置的 httpOnly Cookie，会话过期（401）会自动回到登录页。

**假数据模式**：在地址后加 `?mock=1`（会记在 localStorage，`?mock=0` 关闭），或直接双击 `index.html`（file:// 无后端，自动进入假数据模式）。假数据的时钟默认是 v2 存档，可加 `&mockclock=14:57&mockspeed=5` 快速看收盘小结，`&mockrules=v1` 看经典存档。

**生产部署**：`docker compose up -d --build mobile`（或整套 `docker compose up -d --build`），镜像见 `Dockerfile`，nginx 模板见 `deploy/nginx.conf.template`（静态 + `/api` 反代 + WebSocket 升级 + 安全响应头/CSP + gzip + `/healthz`）。默认监听宿主机 `MOBILE_PORT`（18001），对外域名 `https://m.a.com/`，网页版 `https://a.com/`（18000）；两者共用同一个后端与数据库，外层 HTTPS/域名分流见 `../deploy/host-nginx.example.conf`。HTTPS 下需在 `.env` 设 `COOKIE_SECURE=true`；两个域名的登录态相互独立（Cookie 不设 Domain），账号与存档共享。

**后端没有的部分**：语言/主题仍是占位。分时曲线由后端 `GET /saves/{id}/market/{code}/intraday` 提供当日历史，WebSocket 只追加增量（刷新页面不丢，也不再插值）。资产曲线与当日盈亏由后端提供（`GET /saves/{id}/equity-curve`、portfolio 的 `day_pnl_*`，换浏览器不丢）。

用桌面浏览器打开时，页面显示在居中的手机尺寸框里。也可以打开 DevTools 的设备模式（如 iPhone 14，390×844）查看。

## 页面

| 路由 | 页面 | 要点 |
| --- | --- | --- |
| `#/market` | 行情 / 自选 / 事件相关 | 事件模式存档顶部有重大快讯条，分段「事件相关」列出事发与传导股票（注记 事发/传导）。顶部交易状态栏（距午休/收盘、进度条，点开交易时间说明；首次进入自动弹一次）；v2 收盘后自动弹出收盘小结（倒计时到次日 9:30，可“现在就开盘”或“先暂停”），错过时顶部出现“查看昨日小结 ›”；午休/收盘不接单时左滑只提示原因；资产概览（直接显示终值，可隐藏金额）；自选/全部切换、按涨幅排序、搜索（代码/名称）；「全部」走服务端分页，滚动到底自动加载更多；**左滑行情行出现「买入/卖出」**，直接弹出下单抽屉 |
| `#/stock/:code` | 个股详情 | 大字价格；分时/日 K 切换，按住图表显示十字线；五档盘口；我的持仓；相关事件（事件模式存档）；底部固定「卖出/买入」 |
| `#/portfolio` | 持仓 | 总资产、资产曲线（7 日/30 日/全部）、仓位占比；持仓卡片带光晕，卡片内可直接「加仓/卖出」 |
| `#/auto` | 自动交易（二级页，入口在「我的」） | 运行/暂停/停止；规则卡片用一句话描述条件，带开关；新建/编辑规则在抽屉里完成 |
| `#/me` | 我的 | 账户与存档信息（可切换/新建存档；v1 存档标“经典”）、自动交易入口、游戏速度（v2 快/标准/慢，`PATCH /me`；v1 为行情刷新间隔）与交易时间（说明弹层）、交易统计、成交记录（可筛选、游标分页加载更多、查看明细）、设置（暂停行情、导出存档、退出登录可用） |
| `#/news` | 快讯 | 事件模式存档：公告/新闻/政策/突发/传闻按交易日分组，全部/重大/我的持仓/政策/传闻过滤，新快讯实时插入；重大快讯整卡，点开看传导；非事件存档显示“本存档未开启事件模式”与新建入口 |
| `#/event/:id` | 事件详情 | 标签与标题；传导回放（按交易日选择，未来日禁用，节点涨跌为行情色）；强度/滞后隐藏（情报卡 ⑥）；后续快讯 |
| `#/chain?focus=行业` | 产业链 | 行业搜索；上游/下游/同题材；只公开结构，未揭示的边显示锁 |
| `#/play` | 玩法 | 各玩法分区（每日挑战、预测市场、真实复盘）；每日挑战卡有 4 段回合条、倒计时、参加 / 进入回合 / 去交易 / 查看复盘按钮；未上线的分区显示「即将开放」占位 |
| `#/challenge` | 每日挑战（二级页） | 阶段与倒计时、回合条；未参加时可参加（挑战存档，行情与全服一致）；当前回合用预测卡作答（截止前可改）；本场各轮的答案、判定结果与全服均值；往期挑战可进复盘 |
| `#/challenge/board` | 挑战排行榜（二级页） | 今日（综合 / 预测 / 交易）、本周、总榜；我的名次；今日未结算时提示并默认切到本周；底部公平性（承诺指纹，结算后可验证） |
| `#/pm` | 预测市场列表（二级页） | 进行中 / 已结束；合约卡显示最热选项与概率；打开即接入全服推送 |
| `#/pm/:id` | 合约详情（二级页） | 选项概率条、开市以来的概率曲线、买卖面板（份数、预计花费/回款、滑点保护、持仓）；离开即断开推送 |
| `#/pm/records` | 市场记录（二级页） | 我的结算记录：获胜项、兑付、净盈亏 |
| `#/replay` | 真实复盘选关（二级页） | 进行中、关卡（默认匿名标题与导语）、已结算；关卡抽屉里可开启或关闭匿名模式并开始 |
| `#/replay/:id` | 复盘会话（二级页） | 四阶段推进（盘前 / 开盘 / 收盘 / 盘后）；匿名股票与缩放价格；当日消息；预测题（抽屉作答）；只按开盘价或收盘价买卖 |
| `#/replay/:id/reveal` | 复盘揭示（二级页） | 积分、收益与超额；股票真身与完整 K 线；事件影响；题目结果；资产曲线；作者讲解 |
| `#/challenge/:id/review` | 挑战复盘（二级页） | 综合 / 预测 / 交易收益 / 名次与积分；各轮结果；公开的行情种子、盐、承诺原文与 sha256，「验证种子」用浏览器 WebCrypto 本地计算（无法计算时如实提示） |

下单抽屉：可切换买入/卖出，支持市价或限价（价格按 0.01 步进，长按连续变化）。数量按每手 100 股步进，有 1/4、1/2、3/4、全仓快捷按钮。抽屉显示预估金额、手续费和可用资金，能实时校验资金不足、T+1 等情况。成交后显示结果，2.4 秒后自动关闭。抽屉可以下拉关闭，也能点遮罩或按 Esc 关闭。

## 目录

| 路径 | 说明 |
| --- | --- |
| `index.html` | 唯一入口 |
| `dev-server.mjs` | 零依赖开发服务器：静态文件 + `/api` 反代（含 WebSocket） |
| `deploy/` | 生产 nginx 模板 |
| `Dockerfile` | 手机版镜像（只含静态文件，不含 dev-server.mjs、文档） |
| `css/tokens.css` | 颜色、字号、间距、动效变量（唯一的颜色来源） |
| `css/base.css` `components.css` `pages.css` | 基础、组件、页面样式 |
| `js/features/` | 玩法功能（⑤ 起）：`news/` 快讯、事件详情、产业链、行情快讯条、事件相关分段、个股相关事件、收盘小结“今天的大事”；`pm/` 预测市场（玩法分区、列表、合约买卖、结算记录）；`predict/` 预测卡与积分；`challenge/` 每日挑战（挑战卡、挑战页、排行榜、复盘）；`replay/` 真实复盘（选关、会话、揭示）；每个功能自带 mock、store（两套）、页面与 `index.js` |
| `css/features/` | 玩法样式（⑤ 起），颜色只用 tokens |
| `js/lib/` | 工具：转义模板、金额格式化、时钟模型（`clock-model.js`）、API 客户端、store（真实/假数据两套）、SVG 图表、路由（含 query）、玩法挂载点（`slots.js`） |
| `js/mock/` | 假数据（`?mock=1` 时使用），字段与后端 schemas 一致 |
| `js/components/` | 复刻自 React Bits 的组件，以及交易状态栏、交易时间说明、占位卡、抽屉、下单、左滑行 |
| `js/pages/` | 各页面 |
| `tests/` | 前端纯函数测试（`node mobile-prototype/tests/run.mjs`，零依赖；不进镜像）：时钟、快讯与传导纯函数 |

## 配色规则

- 背景分 3 层冷灰（`#0A0B0D` / `#111317` / `#181B20`），文字分 3 级白灰，边框用 6% 透明度的白色。
- 唯一的强调色是青绿 `#3DDBB0`，用于主按钮、选中态和光晕。
- 红涨（`#F6465D`）绿跌（`#2EBD85`）只用于行情数据。买卖按钮用强调色或中性色区分，不用红绿。
