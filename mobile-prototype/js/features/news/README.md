# 快讯 / 事件 / 产业链

手机端的事件行情玩法（事件模式存档）：

- **快讯** tab：公告、新闻、政策、突发、传闻按交易日分组；重大快讯整卡；可按重大、我的持仓、政策、传闻过滤；新快讯实时插入顶部。
- **事件详情**：按交易日回放传导（源行业 → 上下游行业），每条边的强度与滞后天数隐藏，后续还会有情报卡（⑥）。
- **产业链**：只公开谁连着谁；切换行业焦点、搜索行业；点中心行业打开行业抽屉（成分股、关联、最近快讯）。
- **行情页**：顶部重大快讯条；“事件相关”分段（事发 / 传导）。个股页日 K 下方的事件标记与底部“相关事件”；收盘小结“今天的大事”。

新建存档时在“我的 → 切换存档 → 新建存档”里选择“事件模式”（默认开启）。事件模式创建后不可更改。

数据与约定见 `CLAUDE.md`。
