# js/features

玩法功能（手机端 ⑤ 起）。每个子目录自带假数据、两套 store、页面与注册入口，核心页面只留挂载点。约定见 `CLAUDE.md`。

- `news/`：快讯 tab、事件详情与传导回放、产业链、行情页快讯条与“事件相关”分段、个股“相关事件”、收盘小结“今天的大事”。
- `predict/`：预测卡弹层、结算复盘、我的预测、积分与校准、情报卡、称号。
- `challenge/`：每日挑战（玩法页挑战卡、挑战页、排行榜、赛后复盘与种子校验）。
- `replay/`：真实复盘（玩法页分区、选关、会话四阶段推进、预测题、揭示页）。
- `pm/`：预测市场（玩法页分区、市场列表、合约详情与买卖、结算记录；LMSR 报价纯函数与全服推送）。
