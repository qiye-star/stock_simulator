# js/features/replay/ — 真实复盘

用真实历史关卡练习交易和预测。股票名与价格默认隐去，行情只按开盘价或收盘价推进、成交；结束后揭晓真实走势、事件影响与得分。

- 入口：玩法页的“真实复盘”分区（进行中会话、关卡卡）。
- 页面：`#/replay`（选关：进行中、关卡、已结算；关卡抽屉里可选匿名模式并开始）、`#/replay/:id`（会话：四阶段推进、股票与 K 线、当日消息、预测题、买卖）、`#/replay/:id/reveal`（揭示：积分、真身、事件影响、题目结果、资产曲线）。
- 当前使用假数据（两个虚构关卡）；后端复盘接口未上线时显示“即将开放”。
- 数据与约定见 `CLAUDE.md`。
