# 自选模块（watchlist）

在行情页把股票加入或移出自选：点击详情区的“+自选 / -自选”按钮，或点击列表中股票右侧的星标。
自选状态保存在当前存档中，列表可通过“查看自选”按钮只显示自选股票。

## 快速开始
随前端加载，无需配置。

## 目录
| 文件 | 说明 |
|---|---|
| `index.js` | 按钮与星标的交互入口 |
| `controller.js` | 调用接口并乐观更新、失败回滚 |
| `model.js` | 切换自选的纯函数 |

## 接口依赖
- `PUT /saves/{id}/watchlist/{code}`（加入）、`DELETE /saves/{id}/watchlist/{code}`（移除）
