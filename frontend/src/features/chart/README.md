# K 线图模块（chart）

行情详情中的日 K 线与成交量柱状图（约 60 个交易日），支持滚轮缩放、拖拽平移、双指缩放、右键或 Shift 框选放大、悬停十字线。
现价以虚线标出，随每个 tick 更新。切换股票时视口回到最新。

## 快速开始
随前端加载，无需单独配置。选中一只股票即可看到图表。

## 目录
| 文件 | 说明 |
|---|---|
| `index.js` | 功能入口，订阅行情 store 并驱动重绘 |
| `viewport.js` | 视口数学（纯函数，有单测） |
| `render.js` | Canvas 绘制（HiDPI） |
| `interact.js` | 鼠标 / 触摸交互 |

## 操作
- 滚轮：以鼠标位置为中心缩放；拖拽：左右平移；双指：捏合缩放。
- 右键拖拽或按住 Shift 拖拽：框选放大。
- 工具栏：放大、缩小、重置。
