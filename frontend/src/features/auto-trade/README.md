# 自动交易（auto-trade）

按条件自动买入或卖出股票：配置触发条件、数量、价格与风控，然后启动、暂停、恢复或停止。

## 快速开始
1. 在「触发条件」页选择股票、方向、条件类型（价格 / 涨跌幅 / 盈利目标 / 时间间隔）与数量，点「添加股票」。
2. 「风险控制」页可设置止损、止盈、单只最大次数、单次最大金额与全局最大交易次数。
3. 点「启动自动交易」。运行中可暂停 / 恢复，或停止（配置保留）。
4. 「交易记录」页查看统计与执行事件。失败原因按当前语言显示。

注意：涨跌幅以百分数输入（如 2.5 表示 2.5%）；盈利目标仅适用于卖出；买入时该选项自动禁用。

## 目录
| 文件 | 作用 |
| --- | --- |
| `index.js` | 功能入口，导出 `mount` |
| `controller.js` | 表单提交、配置增删改、启停、统计与事件轮询 |
| `view.js` | 配置列表与事件列表的 HTML 模板 |
| `model.js` | 表单校验、请求体映射、视图模型（纯函数） |
| `*.test.js` | 校验、映射、往返与转义的单元测试 |

## 接口
- `GET|POST /api/v1/saves/{id}/auto-trade/configs`，`PUT|DELETE .../configs/{cid}`
- `POST .../auto-trade/start|pause|resume|stop|reset`
- `GET .../auto-trade/events`
- `GET /api/v1/saves/{id}`（读取运行状态与统计）
