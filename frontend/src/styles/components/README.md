# src/styles/components

按页面或组件划分的样式段，由 `../index.css` 统一导入。

| 文件 | 内容 |
| --- | --- |
| `auth.css` | 屏幕切换与登录 / 注册 |
| `common.css` | 通用按钮、通知、错误提示 |
| `notification-types.css` | 通知类型颜色（新增） |
| `saves.css` / `setup.css` | 存档列表 / 开局设置 |
| `layout.css` | 主界面头部与导航 |
| `market.css` / `market-detail.css` | 行情列表 / 详情与图表 |
| `trade.css` / `portfolio.css` / `profile.css` | 交易 / 持仓 / 个人主页 |
| `modal.css` / `time-control.css` | 弹窗与时间控制 |
| `achievement-popup.css` / `tutorial.css` | 成就弹窗 / 新手引导 |
| `scrollbar.css` | 滚动条 |
| `auto-trade.css` / `auto-trade-stocks.css` | 自动交易 |
| `controls.css` / `number-stepper.css` | 表单控件 / 数字步进按钮 |
| `context-menu.css` | 右键菜单 |
