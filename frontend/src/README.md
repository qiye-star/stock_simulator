# src

前端源码根目录。

| 路径 | 说明 |
| --- | --- |
| `main.js` | 应用入口，依次初始化样式、i18n、主题、数字步进按钮与功能模块 |
| `api/` | 后端接口：fetch 封装、重连 WebSocket、类型化端点 |
| `state/` | 发布订阅状态容器与应用全局状态 |
| `i18n/` | 国际化核心、错误码映射与双语文案 |
| `ui/` | 通用 UI 工具（转义模板、DOM、通知、弹窗、格式化、主题） |
| `styles/` | 样式表（由原版 styles.css 切分） |
| `features/` | 功能模块（逐步移植） |
