# docs/10.26-plan/ — 事件驱动玩法实施计划（给 agent）

2026-10-26 立项的“新闻事件 + 产业链传导 + 预测玩法”实施计划。计划阶段文档，尚未实现。

## 边界与不变量
- `00-背景与决策.md` 是本目录的前提：用户已定的决策（目前 1–12）与跨分册共享约定。与其它分册冲突时以 00 为准；改决策先改 00。
- 共享契约归属：事件对象/事件 ID/产业链结构/暂停钩子归 `01`；积分账本与计分纯函数归 `02`；seed 保密与承诺归 `03`。其它分册只引用，不另起一套。
- 计划中的 API、错误码、表名在**实施时**才写入 `docs/CONTRACT.md` 与 `backend/src/stocksim/models/CLAUDE.md`；本目录不是契约来源。
- 实施若碰 `backend/src/stocksim/domain/`、`data/`、`tests/unit/`：按 00 决策 8 由实施该模式的 agent 直接改，遵守纯函数约束并同步相关 CLAUDE.md。
- 跨分册的合入顺序、迁移链、共享文件冲突规避、`saves.mode` 行为矩阵、开放问题汇总以 `06-路线图.md` 为准；改动某分册契约时同步 06 §3/§7/§8。
- `01a-产业链草稿.md` 的边表列名列序固定（上游 | 下游 | 关系类型 | 正负 | 强度 | 滞后 | 说明），转换脚本依赖它。

## 文件地图
- `00-背景与决策.md` 决策、约束、GitHub 调研结论、跨分册约定
- `01-事件行情.md` 模式 A：事件引擎、产业链传导、快讯流、事件模式开关（底座）
- `01a-产业链草稿.md` 82 个行业的上下游边草稿（待人工校对）

- `02-预测卡.md` 模式 B：预测卡、积分账本、计分
- `03-每日挑战.md` 模式 C：全服同 seed 异步挑战、排行、seed 保密
